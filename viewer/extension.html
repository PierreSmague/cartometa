Cartometa Extension for GeoGuessr

A userscript that brings Cartometa into the game itself: the metas for where you've landed show up on screen, no link to paste and no tab to switch to. One-time setup, about a minute.

Get the script on Greasy Fork Already have Tampermonkey? Skip to step 3

Setting it up

  1. Install a userscript manager

    The script needs a userscript manager to run in your browser — Tampermonkey is the most common one and works on Chrome, Firefox, Edge and most other browsers. Install it from your browser's extension store if you don't already have one.

  2. Enable Developer mode (Chrome & Chromium browsers)

    Chrome disables userscripts by default since it moved to Manifest V3. Go to chrome://extensions and turn on Developer mode (top right corner) — that's what unlocks Tampermonkey's ability to run userscripts on this version of Chrome. Without it, Tampermonkey stays installed but never actually runs anything, with no warning.

    See Tampermonkey's FAQ on this setting if Developer mode alone doesn't do it — some Chrome versions instead expose a separate Allow User Scripts toggle on Tampermonkey's own details page. Firefox doesn't need this step.

    Same steps on: ChromeEdgeBraveOpera

  3. Install the script

    Open the Cartometa Extension for GeoGuessr page on Greasy Fork and click Install this script. Your userscript manager takes it from there.

  4. Start a fresh round

    Open a new tab (or restart your browser) before playing — a userscript only attaches to tabs opened after it was installed. Then play GeoGuessr as usual: the matching metas appear on their own.

Nothing showing up? Double-check step 2 first — it's the one most people skip on Chrome. Still stuck? Ask on the Cartometa Discord.
