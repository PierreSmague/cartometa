Anki integration
  1. Install Anki and the AnkiConnect add-on (code 2055492159).
  2. In Anki: Tools → Add-ons → AnkiConnect → Config, add "https://cartometa.com" to webCorsOriginList.
  3. Restart Anki, keep it open, and click the button again. Allow the browser’s local-network permission if it asks.

Works in Chrome, Edge and Firefox. Safari does not let pages talk to local apps.
