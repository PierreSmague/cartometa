# Images sur les metas proposées — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Permettre d'attacher une image (Ctrl+V ou glisser) à une meta importée `tag-` directement depuis la file de revue, sans qu'un re-run d'import ne l'efface.

**Architecture:** Trois retouches ciblées au socle existant : `save_image` accepte les ids `tag-` et sait mettre à jour `data/metas/<CC>-tagged.json` (l'image elle-même va dans `data/manual/<CC>/images/`, versionné, car une capture est irremplaçable) ; l'importeur préserve `image` entre les re-runs comme il préserve `extracted_at` ; le client colle/dépose sur la meta courante via la route `/api/meta/image` existante.

**Tech Stack:** Python ≥ 3.14, JS vanilla (pas de harnais JS — `node --check` seulement). Complément du plan `2026-08-10-import-tagged-json.md`, sur la même branche `import-tagged-json`.

## Global Constraints

- Tests : `uv run python -m pytest` (jamais `uv run pytest` — os error 4551 sous Windows).
- Ids attachables : `man-` + 4 hexa (existant) et `tag-` + 6 hexa (nouveau) — rien d'autre ; un id Plonk It (4 caractères sans préfixe) reste refusé.
- L'image d'une meta `tag-` est écrite dans `data/manual/<CC>/images/<id>.<ext>` (versionné) ; seul le champ `image` du fichier `-tagged.json` (gitignoré) la référence.
- Contraintes d'image inchangées : PNG/JPEG/WEBP/GIF, 8 Mo max, mêmes messages d'erreur.
- Un collage pendant l'édition d'un contour ne doit PAS réinitialiser le dessin en cours (pas de `render()` complet après l'attache).
- Commentaires en anglais dans les fichiers commentés en anglais (manual.py, app.js).

```js
async function attachImage(blob) {
  const item = current();
  if (!item || busy) return;
  busy = true;
  try {
    const stored = await postBytes(`/api/meta/image?id=${item.id}`, blob);
    clearError();
    item.image = stored.image;
    // No full render(): it would reset an outline in progress. The image
    // pane is the only thing that changed.
    document.getElementById('image').src = stored.image;
  } catch (err) {
    showError(`Image refused for ${item.id}: ${err.message}`);
  } finally {
    busy = false;
  }
}
```

3. Ajouter les deux listeners en fin de fichier (avant `loadQueue()`) :

```js
document.addEventListener('paste', (event) => {
  // The manual form's own paste handler takes over when it is open.
  if (isManualFormOpen()) return;
  const found = [...(event.clipboardData?.items || [])]
    .find((candidate) => candidate.type.startsWith('image/'));
  if (!found) return;
  event.preventDefault();
  attachImage(found.getAsFile());
});

const sourcePane = document.getElementById('source');
sourcePane.addEventListener('dragover', (event) => event.preventDefault());
sourcePane.addEventListener('drop', (event) => {
  event.preventDefault();
  if (isManualFormOpen()) return;
  const file = event.dataTransfer.files[0];
  if (file && file.type.startsWith('image/')) attachImage(file);
});
```
